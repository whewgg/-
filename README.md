中国法律条文全库（lawlib）

**解决不懂劳动法，左手力气大，右手大力气的问题**
本技能提供 154 部中国现行法律法规（含部分行政法规）的完整条文本地查询能力，共 12200 余条（含民法典 7 编 1260 条），数据提取自国家法律法规数据库（flk.npc.gov.cn）官方文本。涵盖宪法及修正案、宪法相关法、民商法、经济法、财税法、社会法、刑法、行政法、诉讼程序法 9 大类，自包含无需其他法律技能。
数据文件

所有条文存放在本技能目录 data/ 下，每部法律一个 markdown 文件，文件名格式为 法律全称_最新修正日期.md（如 中华人民共和国公司法_20231229.md）。

    data/00-目录索引.md：全部 154 部法律法规的分类索引，含全称、条数、最新修正日期、对应数据文件名。

查询方法

    按法律名称查询：先查 00-目录索引.md 确定数据文件名，再用 Grep 在该文件内搜索。
    按条号查询：在目标法律文件中 Grep 第X条（条号为中文数字，如 第六十三条；部分法律阿拉伯数字条号也可能存在，两种写法都可试）。
    按关键词查询：直接 Grep 整个 data/ 目录（如 定金、格式条款、滞纳金），命中后给出法律名称、条号与原文。
    按主题查询：先在 00-目录索引.md 按 9 大分类缩小范围，再在相关几部法律中检索，效率更高。
    跨法律比较（如比较公司法与证券法对信息披露的规定）：分别在两个文件中检索后对照列出。

任务工作流
法律情况判断（案例分析）

    提取事实要素：主体、行为、时间、结果、争议焦点。
    确定主题方向，查 00-目录索引.md 的 9 大分类和下方速查表，锁定 1-3 部候选法律。
    在候选法律中检索相关条文（关键词 + 条号），找出构成要件。
    将案情事实与构成要件逐一比对（涵摄），得出结论。
    检查效力规则：特别法优于一般法、上位法优于下位法、新法优于旧法；行为发生在旧法时期的，注意法不溯及既往与"从旧兼从轻"（刑事）原则，引用时必须注明所用版本日期。

引用

    引用前必须已在 data/ 中 Grep 命中原文，禁止凭记忆复述条文。
    格式：「《法律全称》(修正年份) 第X条第X款第X项」+ 原文摘录；只需一款一项时引用该款该项，不必整条照抄。
    同一问题涉及多部法律法规时，按 法律 → 行政法规 的效力层级排列，并注明何者优先适用。

做题（法考/练习题）

讲解方式：代入式讲题（默认开启）。讲题时先把自己带入题目情境，把抽象法条变成"发生在自己身上的事"，帮助理解：

    把案情演一遍：用第一人称复述事实（"假设我就是那个借钱给朋友、没让对方写借条的人……"），把"甲/乙/丙"换成"我/你/他"，让当事人具体化。
    沿着行为走一遍：按时间线一步步走——"我"做了什么、对方怎么回应、矛盾在哪一刻爆发；每走一步，指出这一步涉及的法律关系和考点。
    再退回第三人称做涵摄：有了情境感之后，回到规范分析，把案情事实与 data/ 中条文的构成要件逐一比对——此时要件已经很容易对上号。
    代入不等于凭感觉：代入只用于帮助理解，结论必须严格依据条文原文；禁止因"身临其境"就用生活直觉代替法条判断。

    示例（讲"定金罚则"）："假设我付了你 5 万定金买手机，结果我反悔不买了——第一个问题：我违约，定金还能要回来吗？查《民法典》第五百八十七条：给付定金的一方不履行债务，无权请求返还定金。所以我这 5 万拿不回来了；反过来如果是你反悔不卖，就得双倍返还我 10 万。"

做题流程：

    识别题目考点，用关键词在 data/ 全库检索定位条文。
    一律以现行有效文本（索引中的最新修正日期版本）作答；题目如基于旧法，按现行法条分析并指出差异。
    选择题逐项分析：每个选项给出对应法条依据（注明条号），说明对/错理由，最后给出答案。
    案例题按"法律情况判断"流程组织：结论 → 大前提（法条原文）→ 小前提（案情事实）→ 涵摄分析。
    答案末尾列明全部条文出处；库中无相关规定时明确说明，不得编造依据。

回答规范

    引用法条必须使用 data/ 中的原文，不得转述、改写或自行补全，并明确给出法律全称与条号（如「《中华人民共和国公司法》(2023修订) 第八十八条」）。
    条文中「本法第X条」「前款」「本章」等字样为法条交叉引用，引用时保持原样。
    每部法律文件头部标注了最新修正日期，引用时注明版本（如 2023 年修订的公司法），避免与旧法混淆。
    数据库中查不到的内容，明确告知用户，并建议到国家法律法规数据库（flk.npc.gov.cn）核实，不得编造。
    用户询问法律适用意见时：可以提供条文原文与通行理解，但应提示法律意见仅供参考，重大事务建议咨询执业律师。
