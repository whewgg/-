# 中国法律条文知识库（faluku）
可作为ai的skill使用，
本SKILL提供 76 部中国现行法律的完整条文本地查询能力，共 7600 余条，数据提取自国家法律法规数据库（flk.npc.gov.cn）官方文本。涵盖民商法、经济法、财税法、社会法、刑法、行政法、诉讼程序法等 8 大类。



## 数据文件

所有条文存放在本技能目录 `data/` 下，每部法律一个 markdown 文件，文件名格式为 `法律全称_最新修正日期.md`（如 `中华人民共和国公司法_20231229.md`）。

- `data/00-目录索引.md`：全部 76 部法律的分类索引，含法律全称、条数、最新修正日期、对应数据文件名。

## 查询方法

1. **按法律名称查询**：先查 `00-目录索引.md` 确定数据文件名，再用 Grep 在该文件内搜索。
2. **按条号查询**：在目标法律文件中 Grep `第X条`（条号为中文数字，如 `第六十三条`；部分法律阿拉伯数字条号也可能存在，两种写法都可试）。
3. **按关键词查询**：直接 Grep 整个 `data/` 目录（如 `竞业限制`、`定金`、`股东代表诉讼`），命中后给出法律名称、条号与原文。
4. **按主题查询**：先在 `00-目录索引.md` 按 8 大分类缩小范围，再在相关几部法律中检索，效率更高。
5. **跨法律比较**（如比较公司法与证券法对信息披露的规定）：分别在两个文件中检索后对照列出。

## 回答规范

- 引用法条必须使用 `data/` 中的原文，不得转述、改写或自行补全，并明确给出法律全称与条号（如「《中华人民共和国公司法》(2023修正) 第八十八条」）。
- 条文中「本法第X条」「前款」「本章」等字样为法条交叉引用，引用时保持原样。
- 每部法律文件头部标注了最新修正日期，引用时注明版本（如 2023 年修订的公司法），避免与旧法混淆。
- 数据库中查不到的内容，明确告知用户，并建议到国家法律法规数据库（flk.npc.gov.cn）核实，不得编造。
- 用户询问法律适用意见时：可以提供条文原文与通行理解，但应提示法律意见仅供参考，重大事务建议咨询执业律师。

## 注意事项

- 本知识库为静态文本，法律可能修订，应以最新官方文本为准；每部法律的修正日期见 `00-目录索引.md`。
- 数据文件中的条文正文不可改动；如需更新某部法律，替换对应 `data/` 文件并同步更新索引中的日期与条数。
